# Design System

## Theme

Light Mode only.

No dark mode and no theme switching in the PoC.
Light mode is enforced with `<html data-theme="light">`.

Background:
Neutral and professional.

Use subtle color accents only.

## Status Colors

Use the Fragment UI semantic status tokens
(`--color-status-success-*`, `--color-status-warning-*`,
`--color-status-error-*`, `--color-status-info-*`).
Use the `-fg` variants for text to keep WCAG AA contrast.

Success:
Green

Warning:
Amber

Critical:
Red

Info:
Blue

## Spacing

Use generous whitespace.

Avoid dense enterprise UI patterns.

## Typography

Hierarchy:

- Page Title
- Section Titles
- Card Titles
- Body Text

Use consistent Fragments UI typography components.

## Cards

Cards should have:

- Soft border
- Small shadow
- Rounded corners

## Navigation

Simple top navigation only.

No complex sidebar in the first PoC.

## Responsiveness

Desktop first.

Support tablet layout.

Mobile support optional.
