# Vessel Compliance Manager

## Goal

Build a clean and modern dashboard that helps compliance officers determine whether a vessel is compliant.

The solution focuses on three certification domains:

- Vessel Certificates
- Company Certificates
- Crew Certificates

The dashboard must provide an immediate answer to:

"Is this vessel compliant today?"

## Design Principles

- Clean
- Minimal
- Microsoft-inspired
- Executive focused
- Suitable for maritime compliance
- Responsive
- Accessible

## Technology

- React
- TypeScript
- Fragments UI
- Tailwind

## UI Framework

This project must use Fragment UI.

Reference:

https://www.fragmentui.com/docs/vscode-extension-usage

The Fragment UI VS Code extension is available in the development environment.

When generating UI code:

- Prefer Fragment UI components over custom components.
- Use existing Fragment UI patterns whenever possible.
- Follow Fragment UI styling conventions.
- Avoid recreating components that already exist in Fragment UI.
- Keep the design clean and minimal.

## Scope

Proof of Concept only.

No backend integration required.

Use mock data.
