# Dashboard Requirements

## Layout

The dashboard consists of (visual priority order):

1. Top navigation
2. Vessel summary section
3. Compliance overview hero section (primary visual element)
4. Compliance category cards

The Compliance Score is the dominant element on the page.
Visual clarity takes priority over data density.

All sections share the same content container, so the Compliance
Overview hero aligns exactly with the right edge of the
Crew Certificates card. Consistent spacing and margins throughout.
